# Cohere Coral Hackathon Project

I created this project for the Cohere hackathon from LabLab.ai

## Overview

I joined the Cohere Coral Hackathon from LabLab.ai in order to learn more about Langchain, RAG and ML all in one go. Albeit i was taking on a project larger than my current learning, I actually made visible progress with this hackathon. In the end, my program failed as it became apparent to me how hard it is to truly train an LLM from pure scratch, but it allowed me to see how LLMs work and how to utilize API calls in python with Pytorch and Tensorflow for the first time

## Features

- Mainly terminal based communication, as streamlit was an unknown method at the time
- Played around with the LLM's use cases in chatting, data recognition, and training sets
